## 🚀 Sobre mim

Sou desenvolvedora focada em **Realidade Estendida (XR)**, criando experiências imersivas com Unity para dispositivos como **Meta Quest e HoloLens 2**.

Atualmente atuo no desenvolvimento do projeto **CASA ABEn (Meta Quest)**, voltado à criação de uma experiência interativa em realidade virtual.

Tenho experiência prática em:
- Desenvolvimento de aplicações XR
- Interações por eventos e triggers
- Sistemas de mídia (áudio, vídeo e conteúdo dinâmico)
- Integração de lógica de navegação e interfaces imersivas

Além disso, desenvolvo aplicações web modernas com foco em produto e usabilidade.

🎓 Ciência da Computação – UNESC (3ª fase)
